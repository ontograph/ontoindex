# OntoIndex v2.0.7

## Highlights
- **MCP Call-Shape Troubleshooting**: documented the canonical Ontocode-style MCP identity, `namespace="mcp__ontoindex"` plus tool `name`, so `unsupported call: mcp__ontoindex__...` is recognized as a client-router problem instead of an OntoIndex server failure.
- **Generated MCP Docs Clarified**: future generated MCP function ADR pages now include the canonical namespace/name call shape and the same flattened-name troubleshooting note.
