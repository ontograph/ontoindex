# OntoIndex v2.0.8

## Highlights
- **Setup Reruns Repaired**: `ontoindex setup` now replaces the full
  `[mcp_servers.ontoindex]` block in Codex-compatible `config.toml` files, so
  rerunning setup no longer leaves duplicate `args` keys behind.
- **Release Metadata Refreshed**: public install examples and release-facing
  docs now point to the `2.0.8` artifacts instead of older `2.0.6` or `2.0.7`
  markers.
